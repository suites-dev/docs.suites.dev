# Divio Documentation Classification

Use this skill to give each documentation page one primary job.

Read the [Divio introduction](./divio-docs-introduction.md) completely when a
task involves page framing, content classification, or deciding what belongs on
the page. Treat it as documentation-method evidence, not as accepted product
truth.

For each page:

- Choose one primary mode: tutorial, how-to, reference, or explanation.
- Match the structure and level of detail to that mode.
- Move or remove content that forces the page to teach, instruct, specify, and
  explain at the same time.
- Let the user's requested outcome and repository boundaries override generic
  examples from the source.
