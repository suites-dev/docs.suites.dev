Use source mapping when a finding should point from executed JavaScript back to exact authored source. A matching path is not enough. Blackbox verifies the complete content-addressed mapping chain.

## Accepted Mapping Cell

The accepted mapping cell is:

- Node CommonJS.
- Regular v3 inline or sidecar source maps.
- Exact `sourcesContent`.
- One process and one isolate.
- Point locations.

ESM, indexed maps, ranges, loaders, `eval`, workers, native DWARF, multi-process, and multi-isolate layouts return `unsupported` unless their exact cell is certified separately.

## Preserve the Mapping Chain

```text
exact executed artifact
→ generated location
→ content-addressed source map
→ exact authored source bytes
```

The mapping provider joins the exact run, attempt, process, isolate, runtime unit, artifact bytes, map bytes, authored bytes, provider implementation, and support profile.

## Read Mapping Results

| Result                  | Meaning                                                                        |
| ----------------------- | ------------------------------------------------------------------------------ |
| `mapped`                | The complete verified chain authorizes an authored location                    |
| `generated-source-only` | The generated location is valid, but no authored location is established       |
| `unsupported`           | The selected mapping cell is outside certified support                         |
| `inconclusive`          | Available facts cannot establish the mapping                                   |
| `integrity-failure`     | Claimed mapping identity conflicts with verified artifacts or runtime identity |

Only `mapped` authorizes an authored source location. Consumers do not parse maps again or reconstruct their own location.

## Model Service Layout Explicitly

Keep service, instance, process, and isolate identity separate. Runtime evidence must attest which exact artifact bytes each service instance loaded.

A foreign runtime unit, process, isolate, provider implementation, or support profile fails integrity. It never silently downgrades to a nearby source location.

## Summary

- Generate regular v3 maps with exact `sourcesContent` for the accepted cell.
- Treat artifacts and maps as content-addressed identities, not paths.
- Keep process and isolate boundaries explicit.
- Show an authored location only after the complete mapping chain verifies.
