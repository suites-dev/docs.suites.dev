:::note Unsupported Setup Input
Artifact-directory and start-command input is not supported. Blackbox returns a structured `unsupported` result before runtime assurance begins.
:::

This future path is intended for projects that already produce a complete runnable artifact directory outside Docker.

## Intended Workflow

When certified, the workflow will:

1. Accept one explicit artifact directory and start command.
2. Create a canonical manifest for the exact selected files.
3. Allocate an owned process, network, storage, and lifecycle boundary.
4. Bind each runtime instance to the selected artifact identity.
5. Admit observation and completion capabilities before execution.
6. Capture one fresh attempt and verify which exact bytes ran.
7. Stop the process and prove cleanup or quarantine the lease.

## What This Page Does Not Promise

This input is not equivalent to the supported Compose path and does not fall back to it. A process started from an arbitrary directory is not assumed isolated or observable.

Public configuration syntax will be documented only after the exact artifact-directory cell completes certification.

## Use the Supported Path

Use [an existing Compose project](/docs/blackbox/guides/use-existing-compose) for the current setup workflow.
