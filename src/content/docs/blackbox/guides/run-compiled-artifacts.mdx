Use this planned path when the project already produces a complete runnable artifact outside containers.

:::note Planned Setup Path
Distribution-artifact input is **planned**, not supported in the current Alpha path. Blackbox must return an explicit unsupported result instead of assuming that an arbitrary process is isolated or observable.
:::

## Intended Input

```text title="Conceptual pseudocode"
distribution
  artifacts: <built output>
  start: <project-owned launcher>
  ready when: <declared readiness condition>
```

This pseudocode communicates intent only. It is not a public configuration schema or command.

## Intended Workflow

When this path is certified, Blackbox will:

1. Identify the exact selected artifacts.
2. Allocate the process, network, storage, and lifecycle boundary.
3. Bind each runtime participant to the selected artifact identity.
4. Admit the observation capabilities required by the behavioral contract.
5. Run one system or E2E test attempt with fresh evidence.
6. Stop the process and prove cleanup or quarantine uncertain resources.

## Use the Current Path

Use [an existing Compose project](/docs/blackbox/guides/use-existing-compose) for the current Alpha workflow. Check [Alpha Support Status](/docs/blackbox/status/alpha-status#application-setup-status) before adopting distribution-artifact input.
