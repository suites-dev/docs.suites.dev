Use the Compose project your team already runs in development. Blackbox treats one allocated project as the owned sandbox for a physical attempt.

## 1. Identify the Owned Topology

Start with the services the selected system test can reach:

```yaml title="compose.yaml, shortened"
services:
  product-service:
    build: ./services/product
    depends_on: [postgres, redis]
  postgres:
    image: postgres
  redis:
    image: redis
```

Document any database, API, queue, cache, volume, or network outside this project. Blackbox cannot present an unowned resource as isolated.

## 2. Make Participation Deterministic

Blackbox needs an exact expected participant inventory before capture starts. Each required participant must identify itself, advertise admitted capabilities, and confirm capture-protocol readiness.

Ambiguous service discovery produces a preflight question or failure. Blackbox never guesses when the guess could change assurance.

## 3. Separate Telemetry and Control

Allow the sandbox provider to inject generated OTLP observation configuration and separate control authorization. Do not reuse public correlation IDs as credentials or expose internal transport variables as project API.

## 4. Prove the Lifecycle

For each independent attempt, the provider allocates a fresh lease, starts the selected topology, waits for required participants, and tears the topology down afterward.

If teardown cannot be established, Blackbox quarantines the lease. It does not reuse uncertain state.

## 5. Run a Small Case First

Use one case that crosses a small number of supported boundaries, such as the product-cache case with Postgres and Redis. Confirm:

- The native Playwright result is visible.
- Required participants and capabilities were admitted.
- Evidence belongs to one attempt and one capture window.
- The effect finding states its exact evidence scope.

## Summary

- Keep the existing Compose topology as the source of the application shape.
- Make owned and unowned resources explicit.
- Give each independent attempt a fresh lease and teardown.
- Expand to parallel workers only after isolation is proven.
