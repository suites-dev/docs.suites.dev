Use this planned path when the application has a repeatable Dockerfile but no Compose topology.

:::note Planned Setup Path
Dockerfile input is **planned**, not supported in the current Alpha path. Blackbox must return an explicit unsupported result instead of falling back to another setup.
:::

## Intended Input

```text title="Conceptual pseudocode"
application build
  dockerfile: <path>
  context: <path>
  ready when: <declared readiness condition>
```

This pseudocode communicates intent only. It is not a public configuration schema.

## Intended Workflow

When this path is certified, Blackbox will:

1. Build the selected Dockerfile and bind the exact image to the attempt.
2. Allocate the network, storage, service, and lifecycle boundary.
3. Admit the participants and observation capabilities required by the behavioral contract.
4. Run the selected system or E2E test with fresh evidence.
5. Stop the environment and prove cleanup or quarantine uncertain resources.

## Use the Current Path

Use [an existing Compose project](/docs/blackbox/guides/use-existing-compose) for the current Alpha workflow. Check [Alpha Support Status](/docs/blackbox/status/alpha-status#application-setup-status) before adopting Dockerfile input.
