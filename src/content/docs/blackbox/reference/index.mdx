## Authority Rule

The public behavioral contract maps to accepted meaning in SuitePlan. From there, authority moves in one direction:

```text
authoring → SuitePlan → RunnerBundle → RunPlan → runtime evidence → analysis → report
```

Each downstream artifact preserves its exact parent identities. It cannot add a claim, reinterpret scope, or turn observed behavior into a new requirement.
