Blackbox adds deterministic runtime verification to a system test. Start with a working demonstration or connect one test you already trust.

Both paths end with the same result: **one flow runs, Blackbox captures what the system did, and the CLI returns separate test and effect verdicts.**

<QuickstartTrackDiagram />

## Run the Demo

Choose the demo when you want to see the complete loop before changing a project.

You will:

1. Run a real Playwright flow against an instrumented Node system.
2. See a passing native test and a passing runtime-effect verdict.
3. Optionally introduce a hidden effect regression that the response assertion misses.

[Run the Demo in 5 Minutes](/docs/blackbox/quickstart/demo)

## Add Blackbox to Your Project

Choose this path when you already have a passing Playwright system test for a local Node service.

You will:

1. Install the CLI and runtime packages; add agent skills only for the agentic workflow.
2. Connect one test through managed Docker or a local Node process.
3. Add a reviewed effect contract and compute the first runtime verdict.

[Add Blackbox to One System Test](/docs/blackbox/quickstart/add-to-existing-test)

## What You Need

| Path         | Requirements                                                                |
| ------------ | --------------------------------------------------------------------------- |
| Demo         | Node 22+, pnpm 9+, and Docker                                               |
| Your project | Node 22+, Playwright, and one passing local system test; Docker is optional |

Requirements and Gherkin are optional. Add them later when you need traceability from product intent to executable behavior.
