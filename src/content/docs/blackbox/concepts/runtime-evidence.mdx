**Runtime evidence** is the sealed record of what supported capture implementations observed while selected system flows ran.

The evidence bundle separates capture from analysis. A test environment can stop before Blackbox evaluates effects, observable decisions, or report policy.

## Capture Has Orthogonal Parts

| Part              | Responsibility                                                             |
| ----------------- | -------------------------------------------------------------------------- |
| Test runner       | Executes tests and reports native outcomes                                 |
| Runner adapter    | Maps runner events, tags, retries, and workers into the Blackbox lifecycle |
| Runner SDK        | Defines framework-neutral attempts and flow identity                       |
| Capture cell      | Isolates the sidecar, SUT, and required infrastructure                     |
| Language capture  | Produces normalized effects and exact native coverage artifacts            |
| Sidecar           | Validates capture integrity and seals the evidence bundle                  |
| Language analyzer | Joins native coverage, source, and debug metadata into neutral decisions   |
| Analyzer          | Reads the sealed bundle offline and computes effect and ODC findings       |

Playwright is the first runner adapter. Node is the first SUT capture implementation. Future adapters and language captures bind to the same protocol.

## Evidence Is Scoped to a Capture Cell

A **capture cell** contains one sidecar plus the SUT and infrastructure needed by its selected tests.

| Isolation | Use it when                                                                 |
| --------- | --------------------------------------------------------------------------- |
| `flow`    | Each selected flow should receive an independent cell. This is the default. |
| `worker`  | Several flows may safely share a worker-owned cell.                         |
| `test`    | Each native test needs its own cell, including tests within one flow.       |

Isolation is a runtime policy, not a property of Playwright workers or Node processes.

## Flow Identity Uses Baggage

Only tests whose tags match a configured flow prefix trigger capture. The default prefix is `@flow:`.

Blackbox carries test and flow identity in W3C baggage. It does not replace the application's `traceparent`, so existing distributed tracing remains under application control.

## The Bundle Is Language-Neutral

The sealed bundle can contain:

- exact source artifacts and source maps;
- normalized boundary effects;
- canonical decision definitions and arm observations;
- runner attempts, retries, outcomes, and partial-run state;
- capture capabilities and producer versions;
- integrity failures and artifact hashes;
- snapshots of the reviewed contract and analysis policy.

Canonical JSON Schemas live in top-level `protocol/` and publish through `@suites/blackbox-protocol`. Language packages bind to those schemas instead of translating TypeScript types into new wire contracts.

## Integrity Comes Before Verdicts

Blackbox fails capture when evidence is empty, incomplete, incompatible, or associated with the wrong cell or service identity. Analysis must not reinterpret a capture failure as an empty successful run.

Negative effect claims are valid only within a complete bundle whose capture implementation declared the relevant capability.
