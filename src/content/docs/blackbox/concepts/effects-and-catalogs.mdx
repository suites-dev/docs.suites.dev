## From Observation to Effect

An **effect** is a normalized fact about supported behavior at a system boundary during one attempt. Typical effects include an HTTP request, database operation, cache operation, or message publication.

OpenTelemetry provides observations. Blackbox admits only observations with the required identity, capability, lifecycle, and evidence joins, then normalizes them into portable effects. A span is evidence input, not automatically an effect.

```text
OpenTelemetry observation
        ↓ admit and verify
normalized effect fact
        ↓ evaluate approved claim
finding and verdict
```

The portable signature uses service, boundary, operation, target, and status. Blackbox records multiplicity separately, so two equivalent Postgres reads remain visible as a count of two.

## Use a Shared Effects Catalog

The **effects catalog** provides reviewed normalization vocabulary. It describes which eligible observations can become a named effect without binding approved behavior to raw span names or trace layout.

The public catalog syntax is not frozen. This is an illustrative view, not a supported schema:

```yaml title="Illustrative effects catalog"
effects:
  product-record-read:
    matches:
      boundary: postgres
      operation: SELECT
      target: products
      serviceId: product-service

  product-cache-read:
    matches:
      boundary: redis
      operation: GET
      target: "product:42"
      serviceId: product-service
```

The catalog explains how evidence is normalized. It does not declare that a product must use Postgres or Redis. A person approves that behavioral claim separately.

## Evaluate Explicit Claims

Blackbox can evaluate presence, absence, cardinality, ordering, and explicit comparison claims. The same sealed evidence and accepted claim produce the same deterministic finding.

Five verdicts keep different failures distinct: `satisfied`, `violated`, `inconclusive`, `unsupported`, and `integrity-failure`. Only `satisfied` passes.

[See the complete effect signature, claim kinds, evidence rules, and verdicts](/docs/blackbox/reference/effects-and-claims).
