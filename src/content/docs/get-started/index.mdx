Suites helps you unit test TypeScript classes built with **NestJS**, **InversifyJS**, or **InjectionJS**. Run your tests with **Jest** or **Vitest**. Suites creates the class and its dependency mocks; your runner executes the tests and checks assertions.

## Supported frameworks and runners

Every framework below works with either test runner:

| Dependency injection framework | Jest | Vitest |
| --- | --- | --- |
| [NestJS](/docs/guides/nestjs/) | Supported | Supported |
| [InversifyJS](/docs/guides/inversify/) | Supported | Supported |
| InjectionJS | Supported | Supported |

Keep your framework and choose the runner that fits your project. The same Suites testing API works across these combinations.

InjectionJS support covers constructor injection. Contextual `inject()` calls, including class field initializers, are not supported. Follow the [InjectionJS guide](/docs/guides/injectionjs/) for a complete example.

**No DI framework?** Use the [standalone `mock()` and `stub()` utilities](/docs/api-reference/mock/) with Jest or Vitest to create test doubles for plain TypeScript code.

Upgrading from Suites 3? See the [migration guide](/docs/migration-guides/from-v3/).
